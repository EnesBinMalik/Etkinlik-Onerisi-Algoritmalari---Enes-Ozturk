# Etkinlik Onerisi Algoritmalari - Enes Ozturk

![Etkinlik Onerisi Algoritmalari - Enes Ozturk — rozet](docs/rozet.svg)

> **Veri analizi · modelleme** — tasarım ve geliştirme: **Enes Öztürk**

---

Hava sıcaklığına göre etkinlik önerme ödevi: Farklı if-else ve koşullu karar yapıları, alternatif çözüm yöntemleri ve karşılaştırmalı analizi. Hazırlayan: Enes Öztürk.

## Öne çıkanlar

- Veri temizleme ve hazırlık
- İstatistiksel özet ve görselleştirme
- Modelleme ve tahmin adımları
- Yönetici özeti ve rapor görünümü

## Kurulum ve çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
```

| Komut | Not |
| --- | --- |
| `npm install` | bağımlılıklar |
| `npm run dev` | geliştirme sunucusu |
| `npm run build` | üretim derlemesi |

## Proje yapısı
